#  Customer Churn Dataset Analysis Dashboard

## 1. Project Title

**Customer Churn Dataset Analysis Dashboard**

## 2. Headline

> Understanding customer churn, revenue, subscription patterns, and customer retention through an interactive Power BI dashboard.

## 3. Short Description

This project focuses on analyzing customer churn data using **Microsoft Power BI**.

The dashboard provides an overview of customer retention and churn along with important business metrics such as **total customers, churn customers, retained customers, churn rate, total revenue, average monthly charges, and average tenure**.

The analysis also looks at churn based on contract type, subscription type, internet service, payment method, senior citizen status, and state.

## 4. Purpose

The main purpose of this project is to understand **why customers leave a service and which customer groups have higher churn**.

The dashboard can help identify:

- Customers who have churned
- Overall churn rate
- Retained customers
- Churn by contract type
- Churn by subscription type
- Churn by internet service and payment method
- Churn among senior citizens
- Revenue contribution by state
- Relationship between monthly charges and churn

## 5. Tech Stack

- **Microsoft Power BI**
- **Power Query**
- **DAX**
- **Data Cleaning**
- **Data Transformation**
- **Data Modeling**
- **Data Visualization**
- **Excel / CSV**

## 6. Data Source

The project uses a **Customer Churn dataset** containing customer-level information related to subscription, billing, services, location, and churn status.

### Main fields used

| Field | Description |
|---|---|
| Customer | Customer information |
| Churn Flag | Indicates whether the customer churned |
| Contract Type | Month-to-Month, One Year, Two Year |
| Subscription Type | Basic, Standard, Premium |
| Internet Service | Type of internet service |
| Payment Method | Customer payment method |
| Senior Citizen | Senior citizen status |
| Monthly Charges | Monthly amount charged |
| Tenure | Length of customer relationship |
| Revenue | Revenue generated |
| State | Customer location |

> Note: The dataset used in this project is for analytical and portfolio purposes.

## 7. Dashboard Features

###  KPI Overview

The dashboard contains important customer and business KPIs:

- **Total Customers:** 166
- **Churn Customers:** 43
- **Retained Customers:** 123
- **Churn Rate:** 25.90%
- **Total Revenue:** 8.50M
- **Average Monthly Charges:** 1.39K
- **Average Tenure:** 35.97

###  Churn by Contract Type

The dashboard compares churn across:

- Month-to-Month
- One Year
- Two Year

This helps understand how contract duration is associated with customer churn.

### Churn by Subscription Type

Customer churn is analyzed across:

- Basic
- Standard
- Premium

###  Internet Service & Payment Method

A visual analysis is provided for churn based on:

- Internet Service
- Payment Method

###  Senior Citizen Analysis

The dashboard compares churn between:

- Senior Citizens
- Non-Senior Citizens

###  Revenue by State

The dashboard displays revenue generated across different states.

Example states shown include:

- Maharashtra
- Uttar Pradesh
- Karnataka
- Gujarat
- Delhi

###  Monthly Charges & Churn

The dashboard also includes an analysis of **monthly charges in relation to churn**, helping explore whether customer billing levels are associated with churn.

###  Geographic Analysis

A map visualization is used to provide a geographical view of customer churn across different states/locations.
